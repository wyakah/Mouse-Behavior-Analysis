Analysis settings

Likelihood filters model predictions; it does not measure accuracy. Verify this threshold using independently reviewed frames.

Nose time is measured inside your selected cup zones. Chamber occupancy uses body center. Timestamps weight each frame; missing points stay unknown and are not filled in.

Cup proximity is an interaction proxy, not automatic confirmation of sniffing.
