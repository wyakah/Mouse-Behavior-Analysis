    Methods and limits

    The first 1,200 seconds are selected by source presentation timestamps. Every included source frame is decoded and rendered. Cage bounds were inspected across the recording. Original files remain intact.

    Grooming, digging and rearing use frozen DINOv2 appearance, native-neighbor optical flow and temporal classifiers sampled at 2 Hz. Gnawing, jumping and circling use the earlier six-head model with 16 sampled frames per two-second window, repeated across the display interval. Thresholds were fixed before this batch. Scores are held until the next sample; duration estimates have that temporal resolution. No smoothing or minimum-bout filter was added. Intervals without a usable body proposal are unknown. A failed whole-recording localization audit withholds all six totals. This quality filter does not validate retained behavior predictions. The burned-in video scores are raw diagnostic outputs.

    Mouse 745 was previously used as an unlabeled development mouse and is not an independent validation animal. None of these new recordings trained the models. Source-level hashes and model fingerprints are retained in run details. Local accuracy is unknown without a separately reviewed reference set. See the external validation report.
